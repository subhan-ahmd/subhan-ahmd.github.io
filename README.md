# Portfolio

### What's under the hood

- **Physics engine** — Forge2D-powered emoji particles you can drag, throw, and watch bounce around
- **Custom cursor** — Animated reticle with trail particles, crosshair mode on hover, and text brackets
- **Command palette** — Press any key to search everything. Fuzzy matching across sections, projects, and more
- **Glass morphism** — Backdrop blur, sweep gradient glow borders, 3D tilt on hover
- **Swipeable media viewer** — Gallery-style PageView with slide transitions and keyboard nav
- **Responsive** — Full desktop + mobile support with touch interactions

### Easter eggs

There are hidden interactions scattered throughout. A few hints:

- Try tapping an emoji... a lot
- Long-press the name
- Search for something that doesn't exist
- Click the blinking cursor in the footer

Good luck finding them all.

Built with Flutter Web, Forge2D, and Dart
